# Memory-hard password hashing (Argon2id). This is a *deliberate* dependency:
# PBKDF2 in the stdlib was CPU-cheap to parallelise on GPUs, and "no external
# packages" is not worth a weaker password hash. If the wheel cannot be
# installed, the service degrades to hashlib.scrypt (also memory-hard) and says
# so at boot — it never silently falls back to PBKDF2.
